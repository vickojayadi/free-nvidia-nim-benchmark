How to read the results

For speed metrics, lower response times are better. For score, success rate, intelligence, and throughput, higher is better.

Score
Relative performance in this exact run. It is not comparable across different benchmark runs.
Success
How many benchmark requests completed successfully. This is not NVIDIA’s official uptime SLA.
TTFT
Time to first token — how long you wait before the model starts responding.
Throughput
Measured output tokens per second. N/A means the stream could not be measured reliably.

Results include GitHub runner location, shared NVIDIA capacity, and network conditions. Use them as comparative snapshots, not universal latency guarantees.

Intelligence is an external reference and is not included in the performance score.
